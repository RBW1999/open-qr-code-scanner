# open-qr-code-reader

Open source QR Code reader build with Godot 4.7 and OpenXR.

# Setup

Open the project with Godot 4.7.stable

# Addons

- [Godot XR Tools | 4.5.1](https://store.godotengine.org/asset/godot-xr/godot-xr-tools/)
- [Godot OpenXR Vendors Plugin](https://store.godotengine.org/asset/godot-xr/godot-openxr-vendors-plugin/)
